Can these numbers be trusted?

Every figure on this site comes from pinned public files, passes explicit data contracts, and is cross-checked against an independent source where one exists. This page shows how.

How data flows

Local medallion architecture: Python, DuckDB and Parquet, no cloud services. Bronze snapshots are committed with SHA-256 checksums, so every build reproduces the same numbers; accepting new upstream data is an explicit, reviewed step (python -m vg.bronze --refresh). The same layout maps directly to Azure Data Lake + Databricks (bronze/silver/gold Delta tables).

Do DOE export records agree with what Venture Global reports to investors?

Method. DOE volumes (Bcf) are converted at 1,038 Btu per cubic foot and compared with "LNG volumes exported" (or sold, when exported is not reported) in each 10-Q/10-K; Q4 is the annual total minus Q1–Q3. A consistent 1–2% gap in one direction per terminal points to a heating-value or measurement convention, not missing cargoes — cargo counts match.
